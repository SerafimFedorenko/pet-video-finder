# Pet Video Finder — поиск животных на видео

**GitHub:** https://github.com/SerafimFedorenko/pet-video-finder

Приложение с графическим интерфейсом (Tkinter), которое:

1. находит кошек или собак на видео с помощью YOLOv8;
2. вырезает найденных животных из кадров;
3. сравнивает каждый кадр с текстовым описанием или с эталонным изображением;
4. показывает кадры с процентом соответствия, позволяет фильтровать, сохранять кадры и экспортировать результаты в Excel.

## Как устроено сравнение

По умолчанию используется **CLIP** через `sentence-transformers`:

* изображения кодируются моделью `clip-ViT-B-32`;
* текстовые описания — мультиязычной моделью
  `sentence-transformers/clip-ViT-B-32-multilingual-v1`, которая понимает
  русский текст и отображает его в то же пространство признаков CLIP;
* сходство считается как косинус между векторами, отрицательные значения
  обрезаются до нуля, в интерфейсе показывается `cosine * 100%`.

Это не вероятность, а косинусное сходство. Для коротких описаний вроде
«рыжий кот» ориентируйтесь на порог около 20–30%, для сравнения изображений —
около 70–90%.

Модели CLIP загружаются лениво и кэшируются: при первом запуске
`sentence-transformers` скачает их с Hugging Face (около 1 ГБ). Дальше они
берутся из локального кэша. Для режима сравнения изображений текстовый
энкодер не загружается.

Старый вариант на VGG16 и обученных Keras-моделях сохранён как резервный.
Его можно включить переменной окружения:

```bat
set PET_FINDER_BACKEND=legacy
run.bat
```

Другие полезные переменные:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PET_FINDER_BACKEND` | `clip` | `clip` или `legacy` |
| `PET_FINDER_CLIP_IMAGE_MODEL` | `clip-ViT-B-32` | модель изображений |
| `PET_FINDER_CLIP_TEXT_MODEL` | `...clip-ViT-B-32-multilingual-v1` | модель текста |
| `PET_FINDER_CLIP_BATCH_SIZE` | `32` | размер батча CLIP |

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | точка входа приложения |
| `config.py` | общие константы, выбор backend и моделей CLIP |
| `ui/main_window.py` | главное окно Tkinter: только интерфейс, без работы с моделями |
| `controllers/analysis.py` | анализ видео: детекция, вырезание кропов, оценка соответствия |
| `controllers/results.py` | фильтрация, сохранение кадров и экспорт результатов в Excel |
| `comparison.py` | CLIP-сравнение изображений и текста, косинусное сходство, кэш эмбеддингов |
| `networks.py` | старые Keras-модели на VGG16 (резервный backend) |
| `recognizer.py` | детекция животных на видео (YOLO) |
| `frame_cutter.py` | нарезка обучающих кадров из видео |
| `dataframe_creator.py` | построение таблиц с парами изображений |
| `network_train_text.py` | обучение модели «описание ↔ кадр» |
| `network_test_img.py` | оценка старой модели сравнения изображений |
| `test_network.py` | сохранение VGG16-экстрактора и проверка сходства |
| `recognizer_test.py` | тесты детектора |
| `dataframe_creator_test.py` | тесты построения таблиц |
| `comparison_test.py` | тесты CLIP-сравнения без загрузки моделей |
| `controllers/*_test.py` | тесты бизнес-логики без загрузки YOLO и Keras |

Бизнес-логика отделена от интерфейса: `MainWindow` отвечает только за отображение
и реакции на действия пользователя, а обработка видео и работа с результатами
живут в `controllers/`. Контроллер принимает зависимости через конструктор,
поэтому его можно тестировать с поддельными детектором и предикторами.

## Быстрый старт (Windows)

Требуется Python 3.10 или 3.11 (64-bit). В проекте уже есть готовое окружение
`.venv`, но его можно пересоздать.

```bat
setup_env.bat
run.bat
```

Или вручную:

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

> Рабочее окружение находится в `.venv`. Старое сломанное окружение в корне
> (`Lib/`, `Scripts/`, `pyvenv.cfg`) удалено.

## Как пользоваться

1. Запустить `main.py`.
2. Выбрать «Кошки» или «Собаки».
3. Задать интервал между анализируемыми кадрами (в секундах).
4. Ввести описание **или** выбрать эталонное изображение.
5. Нажать «Выбрать видео» и подтвердить обработку.
6. Просматривать кадры кнопками «Назад»/«Вперёд» (или стрелками клавиатуры).
7. При необходимости задать порог в процентах и нажать «Применить фильтр».
8. Сохранить кадр, все подходящие кадры или экспортировать результаты в Excel.

## Данные и модели

Для запуска приложения по умолчанию нужны только `yolov8n.pt` (лежит в
репозитории) и интернет при первом скачивании CLIP. Старые Keras-модели
(`*.keras`, `*.pkl`) и датасеты не входят в git из-за размера; они нужны
только для `PET_FINDER_BACKEND=legacy` и скриптов обучения.

Крупные локальные каталоги (`cats/`, `dogs/`, `* data files/`, `test_data/`,
`.venv/`, `runs/`) исключены через `.gitignore`.

## Тесты

```bat
.venv\Scripts\python.exe check_install.py
.venv\Scripts\python.exe -m unittest discover -s . -p "*_test.py" -v
```

`check_install.py` проверяет версии TensorFlow/Keras/PyTorch/OpenCV,
загружает CLIP, считает сходство изображения с самим собой и делает один
прогон YOLO. Если нужно дополнительно проверить старые Keras-модели:

```bat
.venv\Scripts\python.exe check_install.py --legacy
```

Быстрая установка зависимостей (если установлен [uv](https://github.com/astral-sh/uv)):

```bat
.venv\Scripts\uv.exe pip install --python .venv\Scripts\python.exe -r requirements.txt
```

## Известные ограничения

* Первый запуск занимает время: скачиваются веса CLIP, затем загружается YOLO.
* Обработка видео выполняется на CPU (TensorFlow/PyTorch на Windows без GPU).
* CLIP лучше обобщает, но на близких ракурсах одного животного косинус может
  быть высоким и для разных особей. Для fine-grained задач нужна дообученная
  сиамская сеть или метрическое обучение на своих данных.
* На тестовых парах проекта лучшее разделение по косинусу: CLIP — 80% для
  кошек и 100% для собак, старый VGG16 — 80% и 98%. CLIP при этом не требует
  обучения и работает с текстом на русском.
* Тяжёлые файлы (модели, видео, кадры) не хранятся в git.
